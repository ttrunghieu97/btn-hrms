# shadcn/ui Default (Zinc Dark & White) — Design System

Canonical monochrome product design system for **BTN HRMS**, based on standard shadcn/ui (Zinc dark/white).

---

## 1. Brand Understanding & Aesthetic
- **Character**: Ultra-clean, high-contrast monochrome design system (Zinc).
- **Light Palette**: Pure white cards & background (`oklch(1 0 0)`), stark black primary buttons (`#18181b`), zinc-200 borders (`#e4e4e7`).
- **Dark Palette**: Deep zinc-950 (`#09090b`), pure white primary buttons (`#fafafa`), zinc-800 borders (`#27272a`).
- **Status Semantics**: Authentic Tailwind Emerald (`#10b981`), Amber (`#f59e0b`), Red (`#ef4444`), and Sky (`#0ea5e9`).
- **Typography**: Geist Sans + Geist Mono for tabular numeric alignment.
