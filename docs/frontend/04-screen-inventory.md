# Phase 2B — Complete Screen Inventory (`btn-hrms`)

Every screen in `apps/web` is registered in `src/shared/authorization/route-registry/routes.ts` and validated by `pnpm --filter frontend authorization:check`. Below is the complete inventory across all 68 routes and their shared layout templates.

---

## 1. Shared Layout Templates

1. **Auth Split-Card Template (`src/app/auth/*`)**: Centered glassmorphic card with brand identity, form validation, and error alert banner.
2. **Bento Workspace Dashboard Template (`/workspace`, `/workspace/hr`, `/payroll/dashboard`)**: KPI metric cards strip at top, 2-column responsive Bento grid for charts, pending action queues, and activity feeds.
3. **Domain Tab + DataTable Template (`<DomainHeader>` + `<DataTableToolbar>` + `<DataTable>`)**: Used across CRUD & workflow modules (`employees`, `recruitment`, `performance`, `learning`, `benefits`, `assets`, `expenses`, `leave`, `administration`). Includes URL-synced search/filters (`nuqs`), skeleton loading rows, empty state callout, and modal/sheet action triggers.
4. **Master-Detail / Sheet Inspection Template (`/employees/[id]`, `/payroll/runs/[id]`, `/onboarding/[id]`, `/offboarding/[id]`)**: Workflow hero banner (`*WorkflowHero`) showing current lifecycle stage + contextual primary CTA, tabbed detail cards, and audit/status history timeline.
