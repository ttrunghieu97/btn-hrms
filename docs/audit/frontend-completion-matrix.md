## 4. Deferred Product Decisions (`PRODUCT_DECISION_REQUIRED`) & Separate Release Verdicts

- **`PD-01` (Probation Evaluation Scorecard & Statutory Extension Limits)**: Probation confirmation uses the verified `probation -> working` transition; multi-rater probation scorecards remain deferred pending PO sign-off.
- **`PD-02` (Automated Cron vs Manual HR Trigger for Approved Future Transfers)**: Approved future-dated transfers remain visible in `approved` state on `EmployeeLifecycleWorkflowHero` with an explicit **"Áp dụng ngay"** (`ApplyTransfer`) button for HR on/after `effectiveDate`.
- **`PD-03` (Employee Self-Service Resignation Request)**: Termination and scheduled termination remain HR/Admin-initiated actions; self-service resignation submission is deferred pending PO workflow definition.
- **`PD-04` (Statutory Vietnamese Payroll Calculation — BHXH/BHYT/BHTN/PIT)**: Payroll UI displays prominent provisional warning banners in `PayrollLayout` and `PayrollRunWorkflowHero`, disables Approve/Post/Publish buttons for provisional records, and Backend use cases/handlers/outbox (`ApprovePayrollRunUseCase`, `PostPayrollRunUseCase`, `PayrollDecisionHandler`, `PublishPayslipUseCase`, `UpdatePayrollPeriodUseCase`, `EventOutboxService`, `assertPayrollRunReadyForExportOrPayment`) fail closed with `409 Conflict` (`INVALID_STATUS_TRANSITION`) until `calculationStatus === "CONFIRMED"`.
